==============================================================================
INTRODUCTION                                                    *tasks_nvim*

One Markdown file per task (flat YAML frontmatter), one generated overview
per area. The engine is pure Lua, `:Tasks <verb>` is the editor front end
(dashboard, form, preview), the CLI is `scripts/tasks.lua`. Requires lib.nvim.

Setup: >lua
  require("tasks_nvim").setup({
    vault = "~/vault",
    extra_areas = { "ALL" },
    dashboard = { watch = true, debounce_ms = 250 },
    staleness = { git_timeout_ms = 20000, budget_ms = 30000, repo_bases = {} },
    ci = { lint_timeout_ms = 120000 },
  })
<
There is no built-in vault path; `$TASKS_VAULT` is read when `vault` is unset.
See docs/ENGINE.md (format, checks), docs/COMMANDS.md (verbs) and
docs/BINDINGS.md (keys).
