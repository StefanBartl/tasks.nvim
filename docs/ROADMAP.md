# Roadmap

Open work lives as tasks in the author's vault, not as lines here. Direction:

1. Move the editor front ends into the plugin (`:Tasks <verb>`, dashboard, form, preview).
2. A `done` flow that also closes plans and points to the next task, effort/value estimates, an `actor` field.
3. Rule-set pass (`rules.nvim`), a CI matrix on Linux and macOS, then a first release.
